# inqueue 화면 기준 (사용자가 지적해 맞춘 것)

`assets/inqueue.html` 은 이 기준을 이미 반영했다. 고칠 때 되돌리지 않는다.

## 톤
- 흰 바탕에 무채색, 강조색은 하나(보라)만. 다크 모드도 같은 톤. 회녹색처럼 탁한 색은 「밤티」라고 했다.
- 폰트는 Pretendard. 본문 13.5px. 15px 도 크다고 했다.
- 박스 테두리를 빼고 여백으로 나눈다. 목록은 Linear, 상세는 Notion 문서처럼.

## 정보 위계 (위에서 아래로)
1. 제목 21px, 그 아래 작게 상태·구현 허락
2. **판단**: 내가 정할 것 → 내 판단. 「내 판단」만 회색 박스로 해서 쓸 곳이 보이게
3. 배경: 왜·무엇을, 끝난 기준을 좌우 2칸
4. 조사·구현 기록: 토글이지만 **기본은 펼침**. 접어 두면 불편하다고 했다

## 사람 칸과 Claude 칸
- Claude 칸은 입력받지 않는다(읽기 전용). 연보라 배경, 보라색 `Claude` 칩.
- 사람 칸은 회색 `나` 칩. 배경 없이 글처럼 읽히고 눌러서 고친다.

## 긴 글
- 칸 안에서 스크롤하지 않는다. 입력칸은 글 길이만큼 늘어난다.
- 왼쪽 목록은 고정, 저장 버튼은 화면 아래에 붙어 있다.
- 좌우 패널 사이 여백은 24px. 56px 는 너무 넓다고 했다.

## 글 표시
- Claude 칸은 마크다운으로: 불릿, 번호 목록(1, 2, 3), 표, 인용, 굵게.
- 인라인 코드는 본문보다 작은 고정폭 글꼴에 옅은 배경.
- 경로·`파일:줄` 은 백틱이 없어도 인라인 코드로 보인다. 예/아니오, ai/me, 날짜는 코드로 만들지 않는다.

## 아이콘
- 글자 모양 화살표(▸ ▾)는 쓰지 않고 CSS 꺾쇠로 그린다.
- 상태 점: `ai` 빈 원, `me` 강조색 점, `done` 회색 점.

## 아직 안 한 제안(사용자가 고르면 한다)
- 내가 쓴 칸도 평소엔 마크다운으로 보이고 누를 때만 입력

## 질문 카드 (판단을 빠르게)
- 근거가 멀면 판단이 느리다. 질문마다 추천·이유 한 줄·선택 버튼·근거를 한자리에 둔다.
- 근거는 `path:line` 만이 아니라 원문 한두 줄을 같이 보인다. 근거가 없으면 「근거 없음」 을 드러낸다.
- 전부 답하거나 덧붙일 말을 적어야 넘길 수 있다. 「위 표」 같은 말 없이 질문 하나만 읽고 답할 수 있어야 한다.

## 지난 판단
- 판단 구역 아래 별도 구역. 최신 회차가 위. 회차마다 「n회차 · 시각 · 내 답 요약」 한 줄이고 최신 회차만 펼친다.
- 물결표 하나(~78장)가 취소선이 되지 않게 `~~두 개~~` 만 취소선으로 본다.

## 조사 기록
- 최신이 위. Claude 는 `### n회차 · 한 줄 결론` 블록을 맨 위에 넣고, 페이지는 회차마다 접어 최신만 펼친다.

## 보고 있는 화면을 건드리지 않는다
- AI 가 티켓을 바꿔도 열어 둔 내용을 다시 그리지 않는다. 위에 「새 내용이 있어요」 띠만 띄우고, 사람이 눌러야 바뀐다. 내가 저장했을 때만 바로 다시 그린다.

## 좁은 화면
- 옆 패널처럼 좁게 띄워도 잘리지 않아야 한다. 860px 아래는 목록과 티켓을 위아래로 쌓고 목록 높이는 34svh 로 제한한다.
- 격자 칸은 `minmax(0,1fr)` 로 둔다. 안 그러면 한 줄로 자르는 글(회차 요약)이 칸을 넓혀 오른쪽이 잘린다.

## 쓰던 글을 잃지 않는다
- 페이지를 다시 발행하면 열린 화면이 새로 불러와진다. 저장 전 글과 고른 답은 입력하는 대로 브라우저 임시 저장소에 두고 되살린다.

## 상태 바꾸기
- 상태를 드롭다운으로 고르게 하지 않는다(귀찮다고 했다). 버튼 하나가 저장과 상태 변경을 같이 한다.
- `me`: [AI에게 넘기기] [저장] [완료] / `ai`: [저장] [완료] / `done`: [다시 열기]
