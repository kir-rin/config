# inqueue 화면 기준 (사용자가 지적해 맞춘 것)

`assets/inqueue.html` 은 이 기준을 이미 반영했다. 고칠 때 되돌리지 않는다.

## 톤
- 흰 바탕에 무채색, 강조색은 하나(보라)만. 다크 모드도 같은 톤. 회녹색처럼 탁한 색은 「밤티」라고 했다.
- 폰트는 Pretendard. 본문 13.5px. 15px 도 크다고 했다.
- 박스 테두리를 빼고 여백으로 나눈다. 목록은 Linear, 상세는 Notion 문서처럼.

## 정보 위계 (위에서 아래로)
1. 제목 21px, 그 아래 작게 상태·구현 허락
2. **판단**: 내가 정할 것 → 내 판단. 「내 판단」만 회색 박스로 해서 쓸 곳이 보이게
3. 배경: 왜·무엇을, 끝난 기준을 좌우 2칸
4. 조사·구현 기록: 토글이지만 **기본은 펼침**. 접어 두면 불편하다고 했다

## 사람 칸과 Claude 칸
- Claude 칸은 입력받지 않는다(읽기 전용). 연보라 배경, 보라색 `Claude` 칩.
- 사람 칸은 회색 `나` 칩. 배경 없이 글처럼 읽히고 눌러서 고친다.

## 긴 글
- 칸 안에서 스크롤하지 않는다. 입력칸은 글 길이만큼 늘어난다.
- 왼쪽 목록은 고정, 저장 버튼은 화면 아래에 붙어 있다.
- 좌우 패널 사이 여백은 24px. 56px 는 너무 넓다고 했다.

## 글 표시
- Claude 칸은 마크다운으로: 불릿, 번호 목록(1, 2, 3), 표, 인용, 굵게.
- 인라인 코드는 본문보다 작은 고정폭 글꼴에 옅은 배경.
- 경로·`파일:줄` 은 백틱이 없어도 인라인 코드로 보인다. 예/아니오, ai/me, 날짜는 코드로 만들지 않는다.

## 아이콘
- 글자 모양 화살표(▸ ▾)는 쓰지 않고 CSS 꺾쇠로 그린다.
- 상태 점: `ai` 빈 원, `me` 강조색 점, `done` 회색 점.

## 아직 안 한 제안(사용자가 고르면 한다)
- 내가 쓴 칸도 평소엔 마크다운으로 보이고 누를 때만 입력
- `me` 에서 내 판단을 새로 적고 저장하면 상태를 자동으로 `ai` 로
